## 步骤

- [ ] Cymple PC 端开启对外（VRCFT 兼容）输出，关闭其 VRChat 直连模式
- [ ] PC 上关闭 VRCFT 的 Cymple 模块及其它占用 22999 的程序
- [ ] FGB「模块库 → 原生模块」安装 `cymple-<版本>.zip`
- [ ] 「模块」页把 **Cymple Face Tracking** 设为启动，重启引擎
- [ ] 模块卡片显示活跃，状态页有眼睛与表情输入

## 观察项

- [ ] 注视屏幕中心 → 方向向量接近 (0,0,-1)，转头不带动注视输出
- [ ] 向左/右/上/下看 → `gaze_dir` 的 x/y 分量极化正确（**协议极化仅第三方核对过，必须人眼确认**）
- [ ] 眨眼 → 对应眼睁眼度下降，左右眼独立
- [ ] 张嘴 → `JawOpen`；微笑 → 嘴角上扬 + `MouthCornerSlant`
- [ ] 只开眼动不开面捕（或反之）→ 只有对应域有输出，另一域保持上一有效值或提示无数据
- [ ] 停止 Cymple 输出 → 10 秒内卡片给出「已 N 秒没有数据」；恢复后自动回到活跃
